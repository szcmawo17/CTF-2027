## Исправления и проверки

Исправлены незакрытое начальное SQLite-соединение учебного приложения и освобождение дескрипторов HTTP-процесса. Worker ожидает выход дочернего процесса, при зависании выполняет terminate/kill и прекращает работу, если остановку подтвердить не удалось. Pipe закрываются в finally.

Проверены конкурентные захваты очереди, повтор после потери ответа PUT с прежним содержимым, смена lease, просроченный результат, максимум попыток, дедлайны и финализация, подмена endpoint, отсутствие ключа, права страниц/Admin. Сбой записи очков откатывает последний результат вместе с очками; повтор не удваивает начисления. HTTP внутри atomic запрещён.

Обычные тесты подменяют HTTP/Docker. Flask проверяется in-process клиентом. Настоящий subprocess запускался с недопустимой операцией без сети: проверены spawn, IPC и выход. Принудительное завершение зависания проверено mock-тестами.

## Не выполнено и оставшиеся задачи

1. Реальный HTTP integration test подготовлен, но пропущен: opt-in `CTF_RUN_HTTP_INTEGRATION=1` требует разрешения на временные локальные HTTP-серверы. Сквозной сетевой A/D-цикл не подтверждён. Docker-образ не собирался/не запускался; реальные ограничения контейнера не проверены.
2. Применение 0019 к рабочей базе — только после отдельного разрешения, остановки записей и свежей проверенной копии вне Git. Автоматический откат не выполнять.
3. Периодический запуск/supervisor и мониторинг worker. Просроченные HTTP-раунды завершаются при следующем проходе worker; постоянного планировщика нет. Аварийная смерть родителя ОС может оставить дочерний процесс: daemon не заменяет Job Object/изоляцию процессов.
4. ACL Windows и ротация/резервирование ключа; сроки хранения ciphertext/копий. DELETE не гарантирует физического стирания. Worker доверенный, имеет доступ к общей БД и ключу.
5. Localhost и challenge HMAC не обеспечивают полной изоляции или защиты от MITM/relay. Challenge и запрос идут разными соединениями. TLS, разделение сетей, egress, нагрузочные проверки и PostgreSQL остаются за рамками проверенного режима.
6. Политика досрочного завершения и ограничения будущего публичного API — [POLISH_BACKLOG.md](POLISH_BACKLOG.md). Терминальный ERROR не считается DOWN и не даёт соответствующего бонуса.

Исторические составы и существующие контейнеры не исправлять автоматически. Commit/push/merge и реальные Docker-операции в ревизии не выполнялись; отдельного разрешения на них нет.
